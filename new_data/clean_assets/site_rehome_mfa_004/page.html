    How do I get started with Microsoft MFA?

    Tags 2fa authentication Enroll multi-factor passkey authenticator register

    Overview

    This article provides a guide to getting started with Microsoft MFA.

    Before You Begin​​​​

    To familiarize yourself with Microsoft MFA, we highly recommend reading through What do I need to know about Microsoft MFA? prior to following the below instructions to set up Microsoft MFA.

    Note: You will still need to use Duo to authenticate to some university services, including the VPN. Do not delete the Duo Mobile app from your device during the transition period, which lasts until April 2027. Technology Solutions and your local IT teams will provide further communications when the Duo Mobile app is no longer needed.

    Registering Microsoft MFA methods

    To register new Microsoft MFA methods:

    1. Visit aka.ms/mfasetup and log in with your UIC NetID and password.
       
    2. The Microsoft MFA setup page will display your available sign-in methods. If you haven't already, review How do I choose the right MFA method for me?

      Note: it is strongly recommended that you set up Microsoft Authenticator as a backup method, while also setting up passkeys as your primary methods on your commonly used devices for the best sign-in experience.


       
    3. Select + Add sign-in method
      1. If you have not yet done so, set up the Microsoft Authenticator mobile app. This will be an important backup MFA method.
      2. If you have already set up the Microsoft Authenticator app, follow the instructions for setting up a Passkey to have the simplest sign-in experience.
      3. If you have a USB security key, follow the Security Key setup instructions.
      4. Finally, if you have a C200 hardware token, jump to setting up a Hardware Token.

    The below instructions allow you to set up a passkey in Microsoft Authenticator, as well as push-style MFA and one-time passcodes, in one smooth process.

    Note: Passkey in Microsoft Authenticator requires a mobile device running iOS 17+ or Android 14+. If your device is below these minimum requirements, select Microsoft Authenticator (the third option down) instead as your sign-in method to add.

    Summary instructions are provided below for setting up a Passkey in Microsoft Authenticator. More detailed instructions can be found on Microsoft's support site.

    1. Visit aka.ms/mfasetup and select Add Sign-in Method. On the following screen, select Passkey in Microsoft Authenticator


       
    2. Use your mobile device to install the Microsoft Authenticator app on your iOS or Android device. Note: your device must be running at least Android 14 or iOS 17.


       
    3. When first opening the Authenticator app, decide whether to share additional data to Microsoft and select Continue.
       
    4. Select Work or school account in the Authenticator app to continue.


       
    5. Sign in to your UIC account, verifying your identity with Duo 2FA.
       
    6. On the following screen in the Authenticator app, select Continue.


       
    7. The Authenticator app will generate your MFA configuration and then show you an Account Added screen. Select Done.



       
    8. In the Microsoft Sign-in Methods site, select Next.


       
    9. You will see a confirmation screen showing the passkey was successfully completed.


       
    10. If you haven't already done so, move on to setting up a Synced and Device Passkeys for the best sign-in experience.

    1. Visit aka.ms/mfasetup and select Add Sign-in Method. On the following screen, select Passkey.


       
    2. On the next screen, select Next.


       
    3. Once the next screen is displayed, select Next and your device will prompt you to create a passkey in your password manager (e.g. Google Password Manager, Apple Passwords, Microsoft Password Manager, Bitwarden, etc) or on your device (e.g. Windows Hello). Examples are shown for Apple Passwords, Windows Hello, and Bitwarden.







       
    4. Once created, you will be prompted to name your passkey. Enter any name that is easily identifiable to you.

    1. Visit aka.ms/mfasetup and select Add Sign-in Method. On the following screen, select Passkey.

    2. On the next screen, select Next.


       
    3. If prompted, select to save your passkey to a USB Security Key.




       
    4. When prompted, insert the security key.


       
    5. Follow the prompts to choose and enter a PIN for your security key. Note: This is a PIN that you create.  Keep it safe and do not share it with anyone. If you lose or forget your YubiKey PIN, you will have to work with the YubiKeyYubiKey Manager application to reset your PIN, or work with the YubiKey manufacturer directly.



       
    6. When prompted, touch the security key again.



       
    7. Select Allow for the site to interface with the security key.



       
    8. Name your security key, select Next, and you are done!

    1. Visit aka.ms/mfasetup and select Add Sign-in Method. On the following screen, seleect Hardware Token.


       

    2. A pop up window will ask for the hardware token Serial Number. 

      You can find your Hardware Token's serial number on the back of the device. 


       

    3. Enter a name for your Hardware Token.


       

    4. The next pop up will ask for the 6-digit verification code on the device you just registered. Enter the code.


       

    5. The next pop up screen will have the confirmation that your device has been added to your Microsoft account.


       

    6. Your New C200 Hardware token will now be listed on the Security Info screen.

    Once you have registered your desired MFA methods, familiarize yourself with how to sign in using Microsoft MFA.

    Managing Sign-in Methods

    To manage your sign-in methods, visit aka.ms/mfasetup.

    To remove a sign-in method, select Delete next to the method you'd like to remove.

    Note: Do not remove the Duo MFA (external mfa) entry as this is still needed to access some university services, such as the VPN. This method will be removed automatically at the end of the transition period.
