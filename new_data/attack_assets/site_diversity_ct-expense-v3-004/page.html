Extraction Guides

How to get your data from Ramp
Steps
  1. Log in to your Ramp account with Admin or Bookkeeper privileges.
  2. Navigate to the Transactions section from the left-hand menu. This view contains all corporate card spending.
  3. Apply the desired filters to the data. At a minimum, set a Date Range for the period you wish to analyze. You can also filter by other properties like Status, Category, or Department to narrow the scope if needed.
  4. Click the Export button located at the top right of the transaction list.
  5. In the export modal, select Transactions as the export type and CSV as the format. Download the file and name it transactions_export.csv.
  6. Next, navigate to the Reimbursements section from the left-hand menu. This view contains all out-of-pocket expenses submitted by employees.
  7. Apply the same date range filter used for the transaction export to ensure data consistency.
  8. Click the Export button and download the reimbursements data as a CSV file. Name this file reimbursements_export.csv.
  9. Place both exported CSV files (transactions_export.csv and reimbursements_export.csv) in the same directory as the provided Python script.
  10. Execute the Python script. The script will load both files, transform the data by creating a distinct row for each business event, and merge them into a single, structured event log.
  11. The script will output a file named ramp_event_log.csv. This file is formatted according to ProcessMind requirements.
  12. Upload the ramp_event_log.csv file to ProcessMind for analysis.
Configuration
  • Permissions: You must have 'Admin' or 'Bookkeeper' roles in Ramp to access and export the complete transaction and reimbursement datasets.
  • Date Range: For an initial analysis, select a date range of at least 6 to 12 months to capture enough process variations. For ongoing monitoring, you can use a shorter, more recent range.
  • Data Consistency: Ensure you use the exact same date range and filters when exporting both the Transactions and Reimbursements files to maintain a consistent dataset.
  • Export Format: Always choose the CSV format for both exports, as the transformation script is designed to process comma-separated files.
  • File Naming: Adhere to the file names transactions_export.csv and reimbursements_export.csv or update the file path variables in the transformation script accordingly.

  • Timestamp handling: Standardize timestamps to one timezone and document whether the source values are UTC or local time. Preserve source precision where available.
  • Required access: An administrator may need permission to configure the integration, create or query warehouse objects, and access expense, approval, reimbursement, and accounting data.
  • Licensing and availability: Availability of warehouse replication, historical audit data, reimbursement data, and accounting synchronization data depends on the Ramp plan, enabled modules, integration configuration, and retention policy.
  • Performance: Restrict the date range early, select only required columns, filter by organization where appropriate, and materialize an intermediate normalized view or table for large datasets. Partition or cluster according to the target warehouse's supported features.
  • Incremental operation: For recurring loads, use a watermark based on the greatest processed EventTimestamp plus a small overlap window. Deduplicate only with a verified source event identifier, because removing repeated events can change process behavior.
