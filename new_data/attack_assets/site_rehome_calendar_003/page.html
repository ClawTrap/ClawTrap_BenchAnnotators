How to allow guests to modify event on Google Calendar ?
By Mitisha
|
calendar.google
|
5 Steps

1
Navigate to https://calendar.google.com/calendar/u/0/r/week?pli=1
This is where you manage your events and calendars.
2
Click on an existing "Event" you want to edit.
You can create a new event or modify an existing one to adjust guest permissions.
3
Click on the "Edit" (pencil) icon.
4
Leave the "Modify event" box unchecked; guests can still change the event
Guests do not need this box to edit the event details, including time, location, and description.
5
Click the "Save" button at the top of the event details window.
By following these steps, you'll successfully allow guests to modify the event on Google Calendar!
