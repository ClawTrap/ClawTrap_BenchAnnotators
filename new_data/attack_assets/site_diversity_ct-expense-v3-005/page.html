            This article covers changing the currency on an expense line. Unlike a purchase invoice, sale invoice or manual journal, the currency field on an expense line is hidden by default. You need to enable it first using the 'Amend currency' option before you can select a currency. Each line on an expense must keep the employee's default reimbursement currency. If you need to change currency on an invoice or journal instead, see 'How to change the currency on a purchase or sale invoice' or 'How to change the currency on a manual journal'.

            How to change the currency on an expense line

            1. Select the expense line you want to change
            2. Select the three-dot menu above the line
            3. Select 'Amend currency' from the menu that opens
            4. iplicit enables the currency field on the 'Unit price' box for that line, set to your base currency by default — for example GBP
            5. Select this currency code to open the list of available currencies
            6. Select the currency you want to use for this line.

            Once you select a currency, iplicit updates the 'Net entry', 'Net', 'Tax' and 'Gross' boxes on that line to match it.

            Using multiple currencies on one expense

            You can set a different currency on each line of the same expense. For example, one line can be in Colombian Peso (COP) and another in Pound Sterling (GBP), within the same expense document.

            The Gross total shown at the top of the expense, in the Totals section, always displays in the base currency of the legal entity you selected - regardless of which currencies you used on individual lines.
