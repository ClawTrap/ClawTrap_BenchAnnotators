GraphQL scopes

Beta

Zoom GraphQL is in a public beta.

GraphQL scopes operate similarly to REST API scopes. Configure the scope required for the GraphQL object on your Marketplace app page.

See the table below for the scopes and permissions required to view or edit the following GraphQL objects.
